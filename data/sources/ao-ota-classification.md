# Класифікація переломів AO/OTA: загальні принципи

Класифікація AO/OTA (Arbeitsgemeinschaft für Osteosynthesefragen / Orthopaedic Trauma Association) — це універсальна алфавітно-цифрова система кодування переломів довгих кісток. Вона забезпечує єдину мову для опису переломів, планування лікування та наукового аналізу.

Повний код перелому складається з локалізації (кістка та сегмент), типу перелому, групи та підгрупи.

# Кодування локалізації

Кожна довга кістка позначається цифрою:
- 1 — плечова кістка (humerus)
- 2 — променева/ліктьова кістки (radius/ulna)
- 3 — стегнова кістка (femur)
- 4 — великогомілкова/малогомілкова кістки (tibia/fibula)

Сегмент кістки позначається другою цифрою:
- 1 — проксимальний сегмент
- 2 — діафізарний (середній) сегмент
- 3 — дистальний сегмент

Наприклад, код починається з "32" для діафіза стегнової кістки або "43" для дистального сегмента великогомілкової кістки.

# Типи діафізарних переломів

Для діафізарного сегмента виділяють три типи за літерою:
- Тип A — простий перелом (єдина лінія зламу, два фрагменти). Підтипи: A1 — спіральний, A2 — косий (кут ≥ 30°), A3 — поперечний (кут < 30°).
- Тип B — клиноподібний перелом (є проміжний клиноподібний фрагмент, але після репозиції зберігається контакт основних фрагментів). Підтипи: B1 — спіральний клин, B2 — згинальний клин, B3 — фрагментований клин.
- Тип C — складний (мультифрагментарний) перелом, без контакту між проксимальним і дистальним основними фрагментами після репозиції. Підтипи: C1 — спіральний, C2 — сегментарний, C3 — іррегулярний.

Тяжкість перелому зростає від типу A до типу C, що впливає на вибір методу остеосинтезу та прогноз.

# Типи переломів суглобових сегментів

Для проксимального та дистального (суглобових) сегментів літера означає залучення суглобової поверхні:
- Тип A — позасуглобовий перелом (суглобова поверхня інтактна).
- Тип B — частковий внутрішньосуглобовий перелом (частина суглобової поверхні залишається зв'язаною з діафізом).
- Тип C — повний внутрішньосуглобовий перелом (суглобова поверхня повністю відділена від діафіза).

# Практичне значення класифікації

Класифікація AO/OTA використовується для стандартизованого документування діагнозу, вибору тактики (консервативне лікування, інтрамедулярний остеосинтез, накісткова пластина, зовнішня фіксація) та для наукових досліджень. Точне кодування важливе при заповненні історії хвороби та виписних епікризів.
