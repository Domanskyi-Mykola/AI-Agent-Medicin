# Класифікація переломів AO/OTA: загальні принципи

Класифікація AO/OTA (Arbeitsgemeinschaft für Osteosynthesefragen / Orthopaedic Trauma Association) — це універсальна алфавітно-цифрова система кодування переломів. Спершу її створили для довгих кісток (Müller, AO), а в редакції Compendium 2018 вона охоплює переломи й вивихи всього скелета, зокрема хребта (5), таза (6), кисті (7), стопи (8), щелепно-лицевої ділянки (9), лопатки (14), ключиці (15) і надколінка (34); найдетальніше вона розроблена для довгих кісток. Класифікація забезпечує єдину мову для опису переломів, планування лікування та наукового аналізу.

Повний код перелому складається з локалізації (кістка та сегмент), типу, групи та підгрупи. У редакції 2018 року код може доповнюватися кваліфікаторами (qualifications — малі літери в круглих дужках, наприклад локалізація в межах сегмента чи ступінь зміщення) та універсальними модифікаторами (цифри у квадратних дужках, наприклад супутній вивих, дефект кістки, остеопороз).

## Кодування локалізації в класифікації AO/OTA

Кожна довга кістка позначається цифрою:
- 1 — плечова кістка (humerus)
- 2 — променева/ліктьова кістки (radius/ulna); у Compendium 2018 для ізольованих переломів їх кодують окремо: 2R — променева, 2U — ліктьова (наприклад, дистальний відділ променевої кістки — 2R3)
- 3 — стегнова кістка (femur)
- 4 — великогомілкова/малогомілкова кістки (tibia/fibula); у Compendium 2018 ізольований перелом малогомілкової кістки кодують окремо як 4F

Сегмент кістки позначається другою цифрою:
- 1 — проксимальний сегмент
- 2 — діафізарний (середній) сегмент
- 3 — дистальний сегмент
- 4 — малеолярний сегмент (лише для гомілки: код 44 — переломи кісточок; перелом дистального метаепіфіза великогомілкової кістки (pilon) кодують як 43)

Наприклад, код починається з "32" для діафіза стегнової кістки або "43" для дистального сегмента великогомілкової кістки.

## Типи діафізарних переломів за AO/OTA

Для діафізарного сегмента виділяють три типи за літерою (ієрархія: тип → група → підгрупа):
- Тип A — простий перелом (єдина лінія зламу, два фрагменти). Групи: A1 — спіральний, A2 — косий (кут між лінією перелому та перпендикуляром до довгої осі кістки ≥ 30°), A3 — поперечний (той самий кут < 30°).
- Тип B — клиноподібний перелом (є проміжний клиноподібний фрагмент; після репозиції основні фрагменти контактують, зазвичай із відновленням довжини). Групи за Compendium 2018: B2 — інтактний клин (спіральний або згинальний), B3 — фрагментований клин (групу B1 для діафіза не використовують). У попередній редакції (Müller/OTA 2007) розрізняли B1 — спіральний клин, B2 — згинальний клин, B3 — фрагментований клин.
- Тип C — мультифрагментарний перелом: після репозиції між проксимальним і дистальним основними фрагментами немає контакту. Групи за Compendium 2018: C2 — інтактний сегментарний, C3 — фрагментований (мультифрагментарний) сегментарний (групу C1 для діафіза не використовують). У попередній редакції (Müller/OTA 2007) розрізняли C1 — складний спіральний, C2 — сегментарний, C3 — іррегулярний.

Тяжкість перелому зростає від типу A до типу C, що впливає на вибір методу остеосинтезу та прогноз.

## Типи переломів суглобових сегментів за AO/OTA

Для більшості проксимальних і дистальних (суглобових) сегментів літера означає залучення суглобової поверхні (загальне правило):
- Тип A — позасуглобовий перелом (суглобова поверхня інтактна).
- Тип B — частковий внутрішньосуглобовий перелом (частина суглобової поверхні залишається зв'язаною з діафізом).
- Тип C — повний внутрішньосуглобовий перелом (суглобова поверхня повністю відділена від діафіза).

Винятки з загального правила мають власні визначення типів:
- 11 — проксимальний відділ плечової кістки: 11A — позасуглобовий уніфокальний (двофрагментарний), 11B — позасуглобовий біфокальний (трифрагментарний), 11C — суглобовий або чотирифрагментарний.
- 31 — проксимальний відділ стегнової кістки: 31A — вертлюгова ділянка, 31B — шийка стегнової кістки, 31C — головка стегнової кістки.
- 44 — малеолярний сегмент: 44A — інфрасиндесмозний, 44B — транссиндесмозний, 44C — супрасиндесмозний.

## Практичне значення класифікації AO/OTA

Класифікація AO/OTA використовується для стандартизованого опису перелому, планування лікування та наукових досліджень. Код описує лише морфологію кісткового ушкодження і не враховує стан м'яких тканин (відкритий перелом — за Gustilo-Anderson, закритий — за Tscherne), нервово-судинний статус, ризик компартмент-синдрому, супутні ушкодження, вік, якість кістки та загальний стан пацієнта. Тому вибір тактики (консервативне лікування, інтрамедулярний остеосинтез, накісткова пластина, зовнішня фіксація) не випливає з коду автоматично, а ухвалюється з урахуванням усіх цих чинників. Відтворюваність класифікації між спостерігачами прийнятна на рівні типу, але помітно знижується на рівні груп і підгруп. У медичній документації (історія хвороби, виписний епікриз) код AO/OTA доповнює, а не замінює код діагнозу за чинним класифікатором хвороб (МКХ-10 / НК 025:2021).
